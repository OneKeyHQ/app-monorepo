# @onekeyfe/react-native-native-overlay (in-repo development copy)

Layered native overlay host for iOS, Android, and Web: global levels, page
scope, stack / queue / replace strategies, and natively driven enter / exit
animations.

This directory is a temporary development copy. It is synced into
`OneKeyHQ/app-modules` under `native-views/react-native-native-overlay` after
verification, where it replaces `@onekeyfe/react-native-native-sheet`.

- Behavior contract: [docs/SPEC.md](docs/SPEC.md)
- Tests: `npx jest packages/react-native-native-overlay`
