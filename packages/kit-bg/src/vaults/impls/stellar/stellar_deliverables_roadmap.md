# Deliverable Roadmap

## Tranche 1 - MVP

### Deliverable 1
**Description:** Stellar testnet connection established in OneKey App (website version) with account creation support.  
**Measure:** Users can generate Stellar testnet accounts on OneKey App web.

### Deliverable 2
**Description:** Basic send/receive transaction flows enabled on testnet.  
**Measure:** Users can send and receive Stellar test tokens via OneKey App web.

### Deliverable 3
**Description:** Token balances display enabled on testnet.  
**Measure:** Token balances visible in UI.

---

## Tranche 2 - Testnet

### Deliverable 1
**Description:** Stellar support extended to desktop, mobile, and browser extension versions of OneKey App.  
**Measure:** Users can create/send/receive Stellar testnet transactions on all app platforms.

### Deliverable 2
**Description:** Stellar chain support integrated into OneKey hardware wallets (Classic 1S & Pro).  
**Measure:** Users can view and confirm Stellar testnet transactions on hardware wallets.

### Deliverable 3
**Description:** Enable token swap and staking features on testnet, with limited beta release to community testers.  
**Measure:** Selected users can successfully complete swap & staking transactions; feedback collected.

---

## Tranche 3 - Mainnet

### Deliverable 1
**Description:** Stellar mainnet integration live across all OneKey software wallets.  
**Measure:** Users can create/send/receive Stellar mainnet transactions on mobile, desktop, extension, and web apps.

### Deliverable 2
**Description:** Stellar mainnet integration live on OneKey hardware wallets (Classic 1S & Pro) with passphrase security.  
**Measure:** Users can sign and confirm Stellar mainnet transactions on hardware devices.

### Deliverable 3
**Description:** Public release with developer documentation and ongoing support commitment.  
**Measure:** Documentation published; Stellar support available for all users.
